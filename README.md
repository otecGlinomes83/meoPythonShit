# Итоговая аттестация

Автор: Ходырев Михаил Евгеньевич

## Описание

Random Password Generator — это графическое приложение для генерации случайных паролей с настройкой параметров, сохранением истории и загрузкой данных из JSON.

Приложение позволяет:
- задавать длину пароля с помощью ползунка
- включать и выключать группы символов
- генерировать пароль
- копировать пароль в буфер обмена
- просматривать и фильтровать историю
- удалять запись из истории
- сохранять историю в JSON и загружать её при запуске

## Интерфейс

В приложении есть:
- ползунок длины пароля
- чекбоксы:
  - цифры
  - буквы
  - спецсимволы
- кнопка генерации
- кнопка копирования
- таблица истории
- поле фильтра по истории

## Требования и реализация

### Генерация
Для генерации пароля используется библиотека `random`.

### JSON
История хранится в файле `db.json`.
При запуске программа загружает историю из JSON.
После генерации новый пароль добавляется в историю и сохраняется в файл.

### Валидация
Проверяются:
- минимальная длина
- максимальная длина
- выбор хотя бы одного типа символов

## Структура JSON

Файл `db.json` содержит массив объектов истории.

Поля записи:
- `id`
- `password`
- `length`
- `useDigits`
- `useLetters`
- `useSymbols`
- `createdAt`

## Установка и запуск

1. Склонировать репозиторий.
2. Открыть проект в среде разработки.
3. Убедиться, что файл `db.json` лежит рядом с `main.py`.
4. Запустить файл `main.py`.

## Примеры использования

### Пример 1
Пользователь выбирает длину 12, включает цифры, буквы и спецсимволы, затем нажимает кнопку генерации.  
Приложение создаёт пароль и добавляет запись в историю.

### Пример 2
Пользователь выбирает длину 8 и включает только буквы.  
Приложение генерирует пароль только из букв.

### Пример 3
Пользователь не выбирает ни один тип символов.  
Приложение показывает ошибку и не генерирует пароль.

## Тестирование

Проверены случаи:
- минимальная длина
- максимальная длина
- длина меньше минимума
- длина больше максимума
- выбор всех типов символов
- выбор только одной группы символов
- отсутствие выбранных символов
- загрузка истории из JSON
- сохранение истории после генерации
- фильтрация истории
- удаление записи из истории
